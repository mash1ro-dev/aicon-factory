# 復元・更新失敗からの復旧

## アイコン適用を元に戻す

適用結果に返る BackupId は、`Backup/<32桁ID>/manifest.json` に対応します。削除せず保存してください。

```powershell
Import-Module 'D:\アプリケーション\あいこんふぁくとりー\App\AiconFactory.psm1' -Force
Restore-AiconFactoryIcon -BackupId '実際の32桁ID'
```

- 既存 `.lnk` / `desktop.ini`：元の内容と属性へ戻す
- 今回新規作成した `.lnk`：そのショートカットだけを除去
- フォルダー：保存していた表示用属性も復元
- 適用後に対象が編集された、バックアップが変更された：上書きせず中止

失敗時は manifest と original を保全してください。安全確認のため止まったケースで manifest やハッシュを書き換えて強制復元しないでください。原画や ICO は復元処理では削除しません。

## App の更新に失敗した

通常の例外で更新が失敗した場合は、入れ替えた管理ファイルを旧版へ戻します。エラーに出る `.aicon-stage-*` は調査用に残ります。Library / Backup / Logs 内のユーザーデータは更新対象にしません。

更新前の管理ファイルは `Backup/Install-日時-ID/` に保存します。`recovery.json` に対象名が記録されます。初回インストールで旧版がない場合は、この更新用バックアップはありません。

1. GUI と `aicon` の処理を閉じる
2. エラー文と `Backup/Install-*` を保全する
3. `Library` と `Backup` を別の安全な場所へコピーしてから復旧作業を行う
4. 通常の復元が成功していれば、新しい PowerShell で旧版モジュールを読み込んで確認する
5. 旧版の ZIP がある場合は、README と同様に`Root/_package` 内の新しいフォルダーへ展開して、同じ `-Root` へ再インストールする

強制終了・停電などで途中になった場合は、自動復旧を保証しません。管理情報が欠けているとインストーラーは上書きせず停止します。手動作業が必要な場合、`recovery.json` の対象と実ファイルを照合し、**App・起動スクリプト・同梱文書・管理情報のみ**を扱ってください。Library や Backup 全体を旧版で上書きしないでください。

## アイコンが変わって見えない

対象を開き直す、F5 で更新する、ショートカットのプロパティで IconLocation の参照を確認する、の順で確認します。実際の ICO が移動・削除されている場合は参照を直す必要があります。Explorer の強制終了やキャッシュ削除は本ツールでは行いません。

## アンインストール

先に必要なアイコン設定を復元し、必要な Library / Backup / Logs を保存します。その後、専用インストールフォルダーを手動で削除してください。ZIP 展開元も不要なら別途削除できます。PATH や Profile の後片付けは不要です。

インストール開始時の `.aicon-install.lock` は正常終了・通常のエラーでは解放されます。強制終了後に残った場合は、別のインストールが動いていないことと復元先の内容を確認してから、そのロックファイルだけを手動で削除してください。実行中のロックを削除して同時更新を始めないでください。
