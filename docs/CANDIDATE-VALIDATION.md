# 公開候補 Precision RC2 の検証

製品バージョン0.1.0。Windows 11 x64 / Windows PowerShell 5.1 x64 STAで検証。

最終コードで134 PASS / 0 FAIL / 0 UNRUN。従来119項目に縦横比15項目を追加。正方形、横長、縦長、透明余白付き楕円、円、大きな奇数寸法で、全7サイズの実描画行列のX/Y倍率一致・シアー0、小数座標の有効領域・中心、PNG寸法・内容、元画像不変を確認。中間キャンバス寸法の整数化は保存領域だけで、有効領域を独立に伸縮しない。

WPFの元画像と4プレビューはUniform。150%表示（実デバイス倍率X/Y=1.5、Explorer 144 DPI）で確認。元画像デコード寸法180×140を保持。4プレビューは物理16×16 / 32×32 / 48×48 / 256×256。実際のICO各フレームを抽出し、実GUI・専用ダミーフォルダー／ショートカットのExplorer表示を比較。元の青輪郭130×109に対しExplorer62×52。輪郭のピクセル境界やアンチエイリアスは幾何学的な倍率と別に記録し、輪郭の完全一致を合格条件にしない。以前の約0.8%は整数輪郭比較の測定差で、DPIが原因という確定値ではない。Explorerの選択フレームは追跡していない。他DPI・別モニター・別PC・物理マウス操作は未検証。

混在PNG/JPG/JPEG/WebP、一括処理、途中失敗、キャンセル、繰返し、適用・復元、失敗時保全、標準認可、コンソール非表示を再検査。旧コード・ZIP・比較画像は保持。

背景除去・セグメンテーションの機能やUI設定はない。透明余白トリムはalpha>0の外接範囲を使う。合成PNG3枚を現行の既定値で検証し、3 PASS / 0 FAIL。白・黄色の不透明背景が残り、既存の半透明中心alpha128が保持された。元画像SHA256不変。実写0枚。素材11分類中、単色／大きな色差の合成各1枚は切り抜き用途で非推奨、元から透過PNGの合成長方形1枚はその変換に限定して安定、残り8分類は未検証。写真・髪・毛皮・半透明素材一般などへ合成図の結果を一般化しない。製品の背景処理アルゴリズムは変更していない。

検証素材・入力画像・実画面・Logs・Backup・Resultsは配布ZIPに含めない。ZIPの全ファイルSHA256を読み出し照合し、専用Tests配下へ再展開・インストールして再確認する。公開や外部送信は行っていない。
