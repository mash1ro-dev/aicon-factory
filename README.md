# あいこんふぁくとりー v0.1.1 / Icon Factory

好きな一枚を、いつものアイコンに。

PNG・JPEG・静止WebPからWindows用のICOを作るアプリです。バージョンはv0.1.1です。

## 起動

このフォルダの `IconFactory.exe` を起動してください。`App` フォルダとEXEを一緒に保管します。通常のEXE起動ではPowerShellコンソールを表示しません。内部でWindows PowerShell 5.1を使用し、実行ポリシー・Profile・PATH・レジストリ設定は変更しません。管理者権限への昇格も要求しません。

ZIPをローカルの書き込み可能な専用フォルダへ展開してください。アプリ本体の配置先はOneDrive等のクラウドフォルダやリンク経由を避けてください。これは03で設定する対象フォルダの対応範囲とは別です。システム領域、ドライブ直下、UNC、リンク・ジャンクション経由の場所は変更対象にできません。

## 画像をプレビューして保存する

1. 01の「画像を追加」、または画像のドロップで一覧へ追加します。
2. 「仕上がりを確認」で完成プレビューを作ります。この時点ではICOを保存しません。
3. 01の名前または02の番号で画像を切り替え、保存したい画像の「保存する」にチェックします。複数画像の初期チェックはOFFです。
4. 「アイコンの保存先」を確認し、「選んだアイコンを保存」を押します。チェック済み・生成済み・未保存のものだけを保存します。同じ内容の保存済み画像は重複保存しません。

一覧のCtrl／Shiftによる複数選択は「一覧から外す」ための選択です。保存チェック、現在プレビュー中の画像とは独立しています。個別の×、すべて解除も使えます。これらは元画像や保存済みICOを削除しません。解除後は再起動せず新しい画像を追加できます。

1画像ではアイコン名を編集でき、複数画像では元ファイル名を使用します。既存ファイルは上書きせず、必要な場合だけ `_02` などを付けます。

02では大きな完成プレビューを1つ表示し、番号ボタンで画像を切り替えます。サイズ設定は不要です。保存する1つのICOには16／24／32／48／64／128／256pxを必ず含め、表示には同じ生成結果の256×256px画像を使います。GUIからはサイズ別PNGを自動保存しません。

カテゴリは `Image / Audio / Development / Tools / Apps / Business / AI / Other`。「アプリの保管庫に保存（おすすめ）」は `%LOCALAPPDATA%\AiconFactory\Library\ICO\カテゴリ` に保存します。「好きなフォルダに保存」は「フォルダを選ぶ」で指定した既存フォルダへ保存します。どちらも保存前に実際の保存先を表示し、別の場所へ二重コピーしません。

保管庫はWindowsのユーザーごとのローカルデータ領域にあり、アプリの移動や更新で場所が変わりません。保存した ICO を移動・削除すると、設定したアイコンが表示されなくなることがあります。

## 保存先の記憶

保存方法・任意の保存先・カテゴリと、最後にICOの保存に成功した場所を `%LOCALAPPDATA%\AiconFactory\settings.json` に別々に記録します。「アイコンが保存された場所を開く」は最後に成功したICO保存先を開き、再起動直後も利用できます。保管庫と任意フォルダの切り替えや03の適用先は、この成功履歴を書き換えません。

新しい場所に設定がない初回だけ、起動したアプリの隣の旧 `settings.json` を読み取り、未知の項目も含めて引き継ぎます。旧ファイルは変更しません。旧ICOとバックアップは移動・コピー・削除せず、旧保存履歴や明示された任意保存先も元のパスを保持します。新しい設定があれば更新物に同梱された古い設定より優先します。旧ICOを参照する設定先がある場合は、その旧ICOの置き場所を残してください。

前回フォルダが移動・削除された場合やアクセスできない場合は、別の場所へ自動的に切り替えず案内します。「フォルダを選ぶ」から選び直してください。壊れた設定JSONは上書きしません。ICOの保存に成功して設定だけ記録できなかった場合も、その旨を表示します。`settings.json.lock` は設定更新の排他制御用の空ファイルです。

未保存作業がある状態で閉じると確認します。「作業に戻る」で入力・プレビュー・チェック・保存先を保持します。作業内容そのものの再起動後復元は行いません。

## アイコンを設定する（必要な人だけ）

03は02で現在表示中の **保存済み1件** を使用します。小さな画像と「いま設定するアイコン」で対象を確認できます。01の保存チェックとは独立しており、複数チェックでも設定できます。適用直前に、表示中の1枚だけを使うことを確認します。

「アイコンを設定する場所を選ぶ」から「フォルダを選ぶ」または「ファイル・ショートカットを選ぶ」へ進むと、Windows標準の選択画面を開きます。前回選んだ有効な場所を初期表示し、使えない場合はデスクトップ、ドキュメント、ユーザーフォルダの順に確認します。AppDataを初期場所にしません。この選択履歴はICOの保存履歴とは別です。パス入力・ドロップでも種類を自動判別します。

| 設定先 | 処理 |
|---|---|
| フォルダ | 確認後、desktop.iniと表示用属性を変更します。中のファイルは変更しません。 |
| 既存 `.lnk` | 確認後、既存ショートカットのアイコンを変更します。新しいショートカットは作りません。 |
| `.exe / .ps1 / .bat / .cmd` | 元ファイルを変更せず、新しい `.lnk` を作ります。元ファイルは実行しません。 |

新規ショートカットの既定保存先はデスクトップです。「保存先を変更・ショートカット名を編集」から対象と同じフォルダ、指定フォルダ、名前を選べます。これはICOの保存先とは別です。説明を次回から省略しても、適用直前の確認は省略しません。フォルダと既存ショートカットでは新規ショートカット用の項目を表示しません。

確認中に画像や設定先が変わった場合は適用を中止します。キャンセルでは設定先・ICO・元画像・バックアップを変更しません。「次からこの説明を表示しない」はショートカット作成に成功した後で記憶します。

成功すると実際の設定先を表示します。フォルダでは「アイコンを設定したよ。見た目が変わらないときは、少し待ってみてね。」、ショートカットでは「アイコンを設定できたよ。」と案内します。「ほかの場所にも設定する」で設定先だけを空にし、同じ保存済みICOを続けて別の場所へ設定できます。画像・保存チェック・保存先は保持します。同じ場所への同じICOの重複適用は防ぎ、別の保存済みICOへの変更は確認後に行えます。

デスクトップはWindowsの実際の場所を使います。OneDrive等のクラウド属性がある場合はWindows APIで種類・同期ルート・解決先を確認できた経路だけを受け付けます。リンク・ジャンクション・未知の属性・検証失敗は引き続き拒否します。このPCでは、修正後の通常03でOneDrive Desktop内の通常フォルダへの適用・完了文・Explorerの表示・待機後の更新・再起動なしの連続適用について、利用者から確認済みの報告を受けています。自動試験による実マウス操作の検証や、全Windows環境の動作保証ではありません。

適用したICOを後で移動・削除すると参照が切れるため、安定した場所に保管してください。Explorerの即時反映は保証しません。キャッシュ削除やExplorer再起動は行いません。

## アイコンを設定したあとについて

フォルダのアイコンは、変更してもすぐに見た目が切り替わらないことがあります。
そんなときは、少し待ってみてね。
それでも変わらない場合は、デスクトップの何もないところをクリックして、F5キーで表示を更新してみてください。

このPCでは、本人がOneDrive Desktop内の通常フォルダで時間を置いて正常表示されること、既存ショートカットではほぼ即時に反映されることを確認しています。すべてのWindows環境で同じ時間や動作になる保証ではありません。

完了表示は設定内容と必要な属性の保存・検証結果を示します。Explorerの見た目やOneDrive同期完了を検出した表示ではありません。保存できた後に表示更新通知や操作ログだけが失敗した場合は、完了表示に注意文を添えます。書き込み・属性設定・検証の失敗は成功扱いにしません。エラーが出た場合は、待つだけで直ったと判断せず、ログとバックアップを残してください。

## 適用を戻す


通常GUIの新しい適用バックアップは `%LOCALAPPDATA%\AiconFactory\Backup` に保存します。復元はPowerShellコマンドで行います。まずその `Backup\対象ID\manifest.json` の対象を確認してください。旧バックアップは元の場所に残っています。

```powershell
Import-Module .\App\AiconFactory.psm1 -Force
$dataRoot = Join-Path ([Environment]::GetFolderPath('LocalApplicationData')) 'AiconFactory'
Restore-AiconFactoryIcon -BackupId '確認した32桁のID' -Root $dataRoot -WhatIf
```

確認後に `-WhatIf` を外します。旧バックアップを復元する場合は、旧 `Backup` の親フォルダを `-Root` に指定します。適用後に対象が別の方法で変更されている場合は復元を中止します。詳細は [復元手順](docs/RECOVERY.md) を参照してください。

## 対応範囲・検証

- 入力はPNG、JPG／JPEG、静止WebP。SVG・GIF・HEIC・アニメーション画像は未対応です。
- 元画像を変更せず、縦横比と透明部分を保って正方形に配置します。背景の自動除去やAI補正は行いません。
- 入力上限は64MiB、片辺16,384px、総画素2,400万。全面透明の画像は入力できません。
- 複数の設定先へ一括適用する機能はありません。
- 従来のPowerShell API `New-AiconFactoryIcon` / `New-AiconFactoryBatch` は互換性のため明示的な生成・保存APIとして残しています。GUIの保存前プレビュー操作とは異なります。

Windows 11 x64 / Windows PowerShell 5.1で、専用の画像・設定先を用いて変換、保存、確認、キャンセル、拒否、復元、再起動・更新時のデータ保持を検証しています。自動試験のPASSには安全な拒否・キャンセルや模擬クラウド属性を含みます。他PC、OS設定を切り替えたDPI、標準ダイアログの実マウス操作、OneDrive同期完了は未検証です。

## 更新する場合

アプリを閉じ、新しいZIPを別のローカルフォルダへ展開して起動できます。通常GUIの保管庫はアプリ本体と別の場所にあります。旧ICO・設定・バックアップを削除しないでください。初回の旧設定引き継ぎが必要な場合は、旧settings.jsonを保全したうえで新アプリの隣に置きます。

管理情報のある既存インストールを更新する場合は、展開元で `Install.ps1 -Root <既存アプリの絶対パス>` を実行します。無指定時の配置先はユーザーの `%LOCALAPPDATA%\Programs\AiconFactory` です。既存Library・Backup・Logs・settings.jsonは置き換えません。管理情報のない同名フォルダには上書きせず停止します。詳しくは [復元・更新手順](docs/RECOVERY.md) を確認してください。

展開元と配置先は、階層が浅く名前の短いローカルフォルダを選んでください。更新では配置先の中に作業用・退避用フォルダを追加するため、アプリ本体を置ける長さでも更新できない場合があります。インストーラーは既存ファイルを動かす前に、配布元・新旧ファイル・一時保存・バックアップ・失敗時の退避・復元先を含むパスとアクセス可否を確認します。長すぎるパスや使用中のファイルを検出した場合は停止します。Windowsの長いパス設定を変更する必要はありません。

配置先を変更する場合も、以前のICOや適用バックアップは元の場所に残してください。ICOを参照するフォルダやショートカットのために、旧フォルダ全体を削除しないでください。
