# あいこんふぁくとりー / Icon Factory

好きな一枚を、いつものアイコンに。

PNG・JPEG・静止WebPから、Windows用のICOを作るアプリです。画像を1枚ずつ、またはまとめて保存できます。v0.1.0の初回公開版です。

## はじめかた

配布ZIPを、書き込みできる専用フォルダーへ展開してください。展開したフォルダーの `IconFactory.exe` をダブルクリックすると起動します。`App` フォルダーとEXEは一緒に保管してください。

通常のEXE利用では、PowerShellコンソールを表示しません。内部ではWindows PowerShell 5.1を使用し、実行ポリシー・Profile・PATH・レジストリを変更しません。環境の実行ポリシーや書き込み権限によって、起動や保存ができない場合があります。

アプリは管理者への昇格を要求しません。書き込みできる場所で使ってください。システム領域、ドライブ直下、UNC、リンク・ジャンクション経由の場所は変更対象にできません。

## 対応形式・できること

- 入力：PNG、JPG／JPEG、静止WebP。
- 1つのICOに16・24・32・48・64・128・256pxの7サイズを保存。
- 縦横に同じ倍率を使い、元画像の縦横比を保って正方形へ配置。すでに透明な外側の余白を整えます。
- 元画像は変更しません。同名のICOや新しいショートカットは、`_02` などの連番で保存します。
- 1つずつ、ショートカットやフォルダーにアイコンを設定。適用前の状態をバックアップします。
- 失敗したときは短い日本語で知らせ、詳細をアプリ内の `Logs` に保存します。ログを書けなかった場合も画面で知らせます。

## 画像をアイコンにする

1. 「画像を選ぶ」、または画面へ画像をドロップします。
2. 1枚なら名前とカテゴリを確認し、「アイコン化する」を押します。
3. 16・32・48・256pxのプレビューで仕上がりを確認します。

複数画像を選ぶと、一括生成に切り替わります。元画像のファイル名を使って画像ごとにICOを保存し、成功・失敗・中止の件数を表示します。途中に壊れた画像があっても、他の画像を続けます。中止時も保存済みICOは残ります。

ICOとサイズ別プレビューの保存先は、アプリの `Library\ICO\カテゴリ` です。「保存場所を開く」で確認できます。元画像を `Library\Source` へ自動コピーする機能はありません。

## アイコンを適用する

単体モードでICOを作り、対象を選んで「対象へ適用」を押します。一括モードはICOの生成・保存だけで、対象への適用は行いません。

| 対象 | 行うこと |
|---|---|
| 既存の `.lnk` | そのショートカットのアイコンを変更します。 |
| フォルダー | `desktop.ini` とフォルダーの表示用属性を変更します。 |
| `.ps1`／`.bat`／`.cmd`／`.exe` | 元ファイルを変更せず、新しい `.lnk` を作ります。EXE本体の埋め込みアイコンは変更しません。 |

新しいショートカットの保存先は、デスクトップ・対象と同じ場所・指定フォルダーから選べます。実機検証では指定フォルダーを使用し、実デスクトップへの保存は試していません。

作成したPS1用ショートカットはWindows PowerShellの `-NoProfile -File` で起動する設定です。PS1・BAT・CMD・EXE本体を起動する試験は行っていません。アプリ本体のコンソール非表示は、これらのショートカット起動には適用されません。

## 適用前へ戻す

復元はPowerShellコマンドで行います。GUIに復元ボタンはありません。

Windows PowerShell 5.1を開き、アプリのフォルダーへ移動してください。`Backup\対象のID\manifest.json` の `Path` が戻したい対象か確認し、`Id` の32桁の値を次のコマンドへ入れます。

```powershell
$appRoot = (Get-Location).Path
Import-Module (Join-Path $appRoot 'App\AiconFactory.psm1') -Force
Restore-AiconFactoryIcon -BackupId '実際の32桁ID' -Root $appRoot -WhatIf
```

`実際の32桁ID` は必ず自分のバックアップIDに置き換えてください。表示された対象を確認したら、`-WhatIf` を外して実行します。

適用後に対象や属性が別の方法で変更されている場合は、復元を中止します。停電・強制終了を含む、すべての障害からの自動復旧は保証していません。復元時にはPowerShell画面を使います。

## できないこと・注意事項

- 背景の自動除去やAI補正はありません。透過PNGがおすすめです。写真や単色背景は、その背景を含めてアイコンになります。
- SVG・GIF・HEIC、アニメーションPNG／WebP、動くアイコンには対応していません。全面が透明な画像も入力できません。
- 一括でショートカットやフォルダーへ適用する機能はありません。
- 入力は64MiBまで、片辺16,384pxまで、総画素数2,400万までです。
- 小さなサイズでは細部の見え方が変わります。髪・細線・半透明素材などの一般的な仕上がりは検証していません。
- 適用したICOを移動・削除すると参照が切れます。適用中は元の保存場所に保管してください。
- Explorerへの即時反映は保証していません。表示が変わらない場合は対象を開き直すかF5をお試しください。アプリはキャッシュを削除したりExplorerを強制再起動したりしません。

## 確認済み環境・検証範囲

Windows 11 x64、Windows PowerShell 5.1 x64 STA、150%表示（144 DPI）で、実EXE・WPFプレビュー・専用ダミー対象のExplorer表示を確認しています。監査時のOSはWindows 11 Home、build 26200です。全回帰の実行当時の詳細buildは記録していません。

既存の自動回帰は134件中134 PASS／0 FAIL／0 UNRUN。単体・一括生成、7サイズ、縦横共通倍率、原本保持、適用・復元、失敗時保全、通常EXEのコンソール非表示などを、専用テスト素材と対象で確認しました。背景診断の合成PNG3枚は別枠です。背景除去の性能試験ではありません。

他のPC・表示倍率・モニター移動・物理マウスのドラッグ＆ドロップは未確認です。自動試験の合格を、すべての画像やWindows環境の保証とはしていません。書き込み権限の異なる全ケースや、Explorerキャッシュの反映時間も検証していません。

詳しい検証範囲は [候補版の検証記録](docs/CANDIDATE-VALIDATION.md)、復元の補足は [復旧手順](docs/RECOVERY.md) を参照してください。

## ソースからランチャーをビルドする

GitHubのソースには `App/Launcher.cs`、`App/launcher.manifest`、`tools/Build-GuiLauncher.ps1` を含みます。Windows PowerShell 5.1 x64から、リポジトリのフォルダーで実行します。

```powershell
powershell.exe -NoProfile -STA -File .\tools\Build-GuiLauncher.ps1
```

Windows標準の.NET Frameworkコンパイラーを使い、同じフォルダーの `IconFactory.exe` を作り直します。通常の利用には、上のRelease ZIPを使ってください。
